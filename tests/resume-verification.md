# 前回の続きから見る（v36）

## 変更
- js/app.js：Vimeoイベントから再生位置を端末保存。コース選択・視聴画面に「前回の続き」を表示。
- css/style.css：受講生ページに限定した再開カード。既存の濃紺・水色トークンを使用。スマホではボタンを縦配置、補助文も14px。
- index.html / admin.html：参照キャッシュ番号を35から36に統一。静的HTML構造の変更なし。
- tests/resume.test.cjs：Node標準テスト18項目。実行は node --test tests/resume.test.cjs。

## 仕様
同じ端末・ブラウザのlocalStorageに、利用者メールとデモ/本番を分けて保存。
30動画・180日まで。5秒以降を約5秒間隔および一時停止・画面離脱時に保存。
残り3秒以内または終了時は再開候補から除外。従来の90%視聴済み判定とは別。
別端末への同期なし。閲覧データの削除や保存拒否時には記録を利用できない。
再開ボタンでは既存data APIで権限・期限・動画IDを確認してから移動。
通常のコース選択では前回の動画を開くだけで、自動的に途中再生しない。
Vimeo公式の開始位置フラグメント #t=秒数s を明示操作時のみ使用。
