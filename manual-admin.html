運営ページに入る

運営ページは、受講生ページと同じメールアドレス・同じパスワードでお入りいただけます。タグに admin が入っている方だけが操作できます。

運営ページのアドレス

https://apps.l-mine.com/rionjuku-app/admin.html

ブックマークしておくと便利です。受講生ページの右上メニューにある「⚙ 運営ページ」からも入れます。

03

動画を追加する

いちばんよく使う操作です。所要1分ほどです。

  1. 「🎬 動画」タブ →「＋ 動画を追加」を押します
  2. コースを選びますコースを選ぶと、そのコースにある章だけがチャプターの候補に出ます。新しい章を作るときは「＋ 新しいチャプター」を選んでください。
  3. レッスンタイトルと、VimeoのURLを入れますURLは https://vimeo.com/1234567890 の形でそのまま貼り付けてください。
  4. 必要なら、視聴開始日・視聴期限を入れます空欄なら「いつでも観られる」です。
  5. 「補足＆タイム」に目次を入れます（任意）0:12:30　本日のテーマ のように書くと、受講生の画面でタップでその場面に飛べる目次になります。
  6. 保存を押しますスプレッドシートの、そのコースの最後の行の下に入ります。

04

お知らせを出す・通知を送る

お知らせは、宛先を選んで出せます。通知（プッシュ）は、お知らせを保存したあとに送ります。

  1. 「📣 お知らせ」タブ →「＋ お知らせを作成」
  2. 見出しと本文を書きます改行はそのまま反映されます。
  3. 宛先をボタンで選びます「👥 全員」か、期・コースのタグを選んでください（複数選べます）。「🔒 運営だけ」は下書き代わりに使えます。
  4. ご出欠などを聞きたいときは、アンケートを入れます1行に1つ書くと、その数だけボタンが並びます。
  5. 保存しますこれで受講生の画面に出ます。
  6. 通知を送るなら、一覧の「🔔 通知」を押しますまず「🧪 自分にテスト」で自分の端末に届くか確かめてから、「📢 全員に送信」を押してください。

通知を送る：9月のゆるカフェ質問会のご案内

宛先は、お知らせの宛先と同じです。 通知をオンにしている方の端末にだけ届きます。

通知を送る

「自分にテスト」で『端末がありません』と出るとき今ログインしているご自身のアカウントで、まだ通知をオンにしていないためです。受講生ページの右上メニュー →「🔔 通知の設定」からオンにしてください。（別のアカウントで運営ページに入っていると、この行き違いが起きます）

アンケートの回答を見る

お知らせ一覧の「📊 回答」から、選択肢ごとの人数と、どなたが何を選んだかの一覧を見られます。スプレッドシートの「お知らせ回答」シートにも同じものが残ります。

閲覧者タブ

絞り込み

上の入力欄で名前・メールから探せます。その下のボタンでタグ・通知オン・LINE連携・停止で絞り込めます。ボタンの数字は、その条件に当てはまる人数です。

新しい受講生を追加する

  1. 「＋ 閲覧者を追加」を押します
  2. お名前とメールアドレスを入れますメールアドレスがログインIDになります。
  3. タグを入れますカンマ区切りです。例：2.5期生,凛コース
    ここに入れたタグと一致するコースだけが、その方の画面に出ます。
  4. パスワードは空のままで大丈夫ですご本人に「はじめての方はこちら」から決めていただく形になります。

パスワードを忘れたと連絡が来たら

やり方手順向いている場面
こちらで決める編集画面の「パスワード」に新しいものを入れて保存し、ご本人へお伝えするすぐ入れるようにしてさしあげたいとき
ご本人に決め直してもらうスプレッドシート「閲覧者一覧」のI列（初回設定）を空にする。その方は再び「はじめての方はこちら」を使えるようになりますパスワードを人に伝えたくないとき（おすすめ）
受講を止められた方「状態」を停止にすると、ログインできなくなります。行を消さずに残しておけるので、再開のときもそのまま戻せます。

07

スプレッドシートを直接さわるとき

運営ページを使わず、スプレッドシートを直接直しても構いません。そのときのお約束です。

シート気をつけること
動画一覧同じコースの行は、続けて並べてください。コース名（A列）と章名（B列）は、空欄にすると上の行と同じとみなされます
閲覧者一覧メールアドレスは小文字・スペースなしで。タグはカンマ区切り
コース設定並び順（C列）は小さい数が上。空欄ならシートの行順になります
プッシュさわらないでください。通知の宛先が自動で記録されています
ログイン履歴記録用です。増えすぎたら古い行を消しても大丈夫です
列の順番は変えないでくださいプログラムが「何列目に何がある」で読んでいます。列の追加・入れ替え・削除をされると、動かなくなります。（右端に新しい列を足すのは大丈夫です）
共有は「制限付き」のままにしてくださいこのシートにはパスワードが入っています。「リンクを知っている全員」に変えると、外から読めてしまいます。
08

こまったときは

受講生から「ログインできない」と言われました

①メールアドレスの打ち間違い（全角・スペース）、②まだ閲覧者一覧に登録がない、③状態が「停止」になっている、の順でご確認ください。閲覧者タブの絞り込みでお名前を検索すると早いです。

「観られるはずの動画が出ない」と言われました

その方のタグと、コース設定のタグが一致しているかをご確認ください。一致していれば、その動画の視聴開始日が未来になっていないか、非公開になっていないかもご確認ください。

画面がずっと「読み込んでいます」のまま

通信が不安定なときに起こります。「再読込」ボタンを押してみてください。何度も続く場合は、開発担当（あかり）までご連絡ください。

「サーバー側でエラーが発生しました」と出ました

スプレッドシートの列がずれている可能性があります。直前に列を足したり消したりされていないかご確認のうえ、ご連絡ください。

動画を間違えて削除してしまいました

スプレッドシートで Ctrl+Z（元に戻す）が効きます。時間が経っていたら、シートの「ファイル → 変更履歴」から戻せます。

受講生に配るURLはどれですか

LINEからご案内するときは末尾に ?uid=[[uid]] を付けたもの、メールなど他の方法のときは付けないもの、と使い分けてください。詳しくはURLリストをご覧ください。
