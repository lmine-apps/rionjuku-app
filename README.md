# 凛穏塾 受講生用 動画視聴アプリ

スプレッドシート＋GAS（Apps Script）だけで動く、会員制の動画視聴Webアプリです。Firebaseは使いません。

- 受講生ページ：`index.html`（ログイン → 自分のコースだけ表示 → 視聴 → お知らせ → アカウント設定）
- 運営ページ：`admin.html`（動画／お知らせ／閲覧者／コース設定）
- バックエンド：`gas/Code.gs`（スプシへの唯一の窓口）
- 動画：Vimeo（限定公開リンクもそのまま貼ればOK）

## できること（v1.1.0）

**受講生**
- メール＋パスワードでログイン（30日保持）
- 自分のタグに合ったコースだけ表示。コース＞章＞レッスンの3階層
- 視聴ページ：Vimeo埋め込み／**補足欄の時刻を目次ボタン化してその場面へジャンプ**／前後の動画／視聴済みマーク
- **視聴開始日・視聴期限**に対応（公開前は「◯月◯日公開」、残り14日以内は⏳残り日数、期限切れはロック）
- **お知らせ**：一覧・未読バッジ・ログイン時ポップアップ・♥いいね・アンケート回答
- **アカウントメニュー**：お名前の変更／パスワードの変更
- スマホはコース一覧がドロワー

**運営（タグに `admin` のある人だけ）**
- 🎬動画：追加・編集・削除（コース／章／タイトル／URL／補足／視聴開始／視聴期限／個別タグ／非公開）
- 📣お知らせ：作成・編集・削除、**宛先タグで誰に見せるか指定**、アンケート選択肢、ログイン時ポップ、回答一覧
- 👥閲覧者：追加・編集・削除、パスワード自動生成、タグ付与、停止、LINE UIDの確認
- 📚コース設定：タグ・並び順・公開／非公開・説明（コース別に「視聴できる人数」も表示）

**まだ入っていないもの**
- Webプッシュ通知（Firebaseプロジェクトを作ってから追加します）
- LINEからの簡単ログイン（土台は実装済み・既定OFF。下記「LINE連携」参照）

## 全体の仕組み

```
ブラウザ（受講生）
   │  メール＋パスワードをPOST
   ▼
GAS門番（Code.gs）───► スプレッドシート「凛穏塾動画一覧」
   │                      ├ 動画一覧（1枚目のタブ）
   │                      ├ 閲覧者一覧
   │                      ├ コース設定
   │                      ├ お知らせ／お知らせ回答
   │                      └ ログイン履歴
   ▼
その人のタグ・視聴期限で観られる動画だけをJSONで返す
```

**ブラウザはスプレッドシートを直接読みません。** パスワード照合もタグ判定もGASの中だけ。
公開前・期限切れの動画URLは、そもそもブラウザへ渡していません。

### ⚠️ 最重要：スプレッドシートの共有をOFFにする

閲覧者のパスワードが平文で入るため、**「リンクを知っている全員」共有は必ずOFF**にしてください（初期状態はONです）。
ONのままだと、URLを知っている人が外部から中身を読めてしまいます。
運営スタッフには「編集者」として個別に招待してください。

## セットアップ（初回だけ・順番どおりに）

### ① スプレッドシートの共有を絞る
1. スプシ右上「共有」→「リンクを知っている全員」→ **「制限付き」に変更**
2. 運営スタッフのGoogleアカウントを「編集者」で個別追加

### ② レクティのデータを「閲覧者一覧」タブに入れる
1. スプシに **「閲覧者一覧」** タブを作る（無ければGASの `setupSheets` が自動で作ります）
2. `import/閲覧者一覧_貼付用.tsv` をメモ帳で開く → `Ctrl+A` → `Ctrl+C`
3. 「閲覧者一覧」タブの **A1セル** を選んで `Ctrl+V`
   - 1行目が見出し（名前／メールアドレス／パスワード／タグ／状態／メモ／登録日／LINE UID）
   - 150名ぶんのタグ（コース名）とパスワードが入ります
   - **とーるさんの行（admin）は `setupSheets` が別途追加します**

### ③ Apps Script（GAS門番）を作る
1. https://script.google.com → 「新しいプロジェクト」／名前は `凛穏塾 動画アプリ門番`
2. `gas/Code.gs` の**全文**を貼り付け（Ctrl+A → Ctrl+V）して保存
3. エディタで関数 `setupSheets` を選んで **実行**（承認画面が出たら「詳細」→「安全ではないページに移動」→許可）
   - 足りないタブ（閲覧者一覧／コース設定／お知らせ／お知らせ回答／ログイン履歴）を自動作成
   - 動画一覧の見出しに **F タグ／G 非公開／H 視聴開始／I 視聴期限** を追加
   - 動画一覧のコース名を**コース設定へ自動登録**（タグの初期値＝コース名）
   - 実行ログに**管理者パスワード**が出るので控えてください（（スクリプトプロパティ ADMIN_EMAIL のアドレス）／タグ`admin`）

### ④ ウェブアプリとしてデプロイ
「デプロイ」→「新しいデプロイ」→ **ウェブアプリ**
- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**全員**（認証はコード側で行います）

発行された `…/exec` を `js/config.js` の `GAS_URL` に貼る。
確認：`…/exec?action=ping` が `{"ok":true,"msg":"pong"}` を返せばOK。

### ⑤ Vimeoの埋め込みドメイン制限
Vimeoの各動画 → 設定 → プライバシー → **「埋め込み」＝特定のドメインのみ**に設定し、公開ドメイン（例：`apps.l-mine.com`）を追加。
管理画面から**複数選択で一括変更**できます。「今後アップする動画の初期設定」も同じにしておくと楽です。
※ドメイン制限はVimeoのPlus以上の機能です。

### ⑥ 公開（GitHub Pages）
`lmine-apps` のリポジトリに置いて公開します（神谷さん案件と同じ置き場所）。
公開URLの例：`https://apps.l-mine.com/rionjuku-app/`

## スプレッドシートの構成

### 動画一覧（1枚目のタブ）

| 列 | 見出し | 内容 |
|---|---|---|
| A | コース名 | 空欄なら上の行から引き継ぎ（今の書き方のままでOK） |
| B | チャプター名 | 同上 |
| C | レッスンタイトル | 一覧に出る名前 |
| D | 動画ＵＲＬ | Vimeoのリンク（`https://vimeo.com/番号` / `番号/ハッシュ` どちらでも） |
| E | 補足＆タイム | `0:12:30　見出し` の行は**視聴ページの目次ボタン**になります |
| F | タグ | この動画だけ特別なタグにしたい時。空欄＝コース設定のタグ |
| G | 非公開 | `非公開` と書くと受講生には出ません |
| H | 視聴開始 | 空欄＝すぐ観られる。`2026-09-01` / `2026年9月1日` / `2026-09-01 21:00` |
| I | 視聴期限 | 空欄＝無期限。**その日の23:59まで**（時刻を書けばその時刻まで） |

### 閲覧者一覧

| 列 | 見出し | 内容 |
|---|---|---|
| A | 名前 | |
| B | メールアドレス | ログインID（重複不可） |
| C | パスワード | 平文。運営が発行して伝える／本人が変更したらここが上書きされます |
| D | タグ | カンマ区切り。例：`凛穏塾2.5期生,卒業生サロン`／運営権限は `admin` |
| E | 状態 | `有効` / `停止`（停止はログイン不可） |
| F | メモ | 自由記入 |
| G | 登録日 | 自動 |
| H | LINE UID | LINEから来た人は自動で入ります |

### コース設定

| 列 | 見出し | 内容 |
|---|---|---|
| A | コース名 | 動画一覧のコース名と**完全一致**させる |
| B | タグ | このタグを持つ人だけ視聴可 |
| C | 並び順 | 小さい数が上 |
| D | 公開 | `公開` / `非公開` |
| E | 説明 | コース名の下に出る一文 |

### お知らせ

| 列 | 見出し | 内容 |
|---|---|---|
| A | id | 自動（連番） |
| B | 日付 | 表示される日付・並び順にも使う |
| C | 見出し | |
| D | 本文 | 改行そのまま表示／URLは自動リンク |
| E | 画像URL | 任意 |
| F | 宛先タグ | カンマ区切り。**空欄＝全員** |
| G | 選択肢 | カンマ区切りで入れるとアンケートになる |
| H | 公開 | `公開` / `非公開`（非公開＝運営だけ見える下書き） |
| I | ポップ | `ON` にするとログイン時にポップアップ |
| J | いいね | ♥の数（自動） |

### お知らせ回答
アンケートの回答が `日時／お知らせid／名前／メールアドレス／回答` で記録されます（同じ人が答え直したら上書き）。

## 日常の運用

### 動画を追加する
`admin.html` → 🎬動画 → **＋動画を追加**
→ コース／章／タイトル／Vimeo URL／補足／（必要なら視聴開始・視聴期限）
→ **同じコースの最後の行の下にスプシへ自動挿入**（受講生側は即反映）
※スプシに直接書いても同じように動きます。

### お知らせを出す
📣お知らせ → **＋お知らせを作成**
- **宛先タグ**：空欄なら全員。`凛穏塾2.5期生` と入れればその期の人だけ
- **アンケート**：`参加します,欠席します` のように入れるとボタンが出て、回答が記録されます
- **ログイン時ポップ**：チェックを入れると、次にログインした人に一度だけポップアップ

### 期が変わったとき
1. 🎬動画で新しいコースを作る（またはスプシに行を足す）
2. 📚コース設定でそのコースの**タグ**を決める（例：`凛穏塾3期生`）
3. 👥閲覧者の**タグ**にそのタグを入れる（卒業生はタグを足すだけで両方視聴可）

## 初回パスワード設定（レクティからの移行者向け）

150名はパスワードを知らない状態で移行しています（レクティは書き出してくれないため、スプシのC列は自動生成した仮のもの）。
そこで**ログイン画面の「はじめての方はこちら」**から、本人がパスワードを決められるようにしてあります。

**流れ**
1. 登録済みのメールアドレスを入力 → 名簿と照合
2. 「〇〇さん、ようこそ」→ 新しいパスワードを2回入力
3. 保存して**そのままログイン**（C列が上書きされ、I列「初回設定」に日時が入る）

**一度設定した人は二度と使えません**（`already_set`）。忘れた人への対応は、運営が
- C列のパスワードを書き換えて伝える、または
- **I列「初回設定」を空にする**（→ もう一度本人に設定してもらえる）

**安全装置（スクリプトプロパティ・すべて任意）**

| プロパティ | 効果 |
|---|---|
| `FIRST_SETUP_UNTIL` | 受付の最終日（例 `2026-09-30`）。過ぎると受付終了。**設定を推奨** |
| `FIRST_SETUP_WORD` | 合言葉。設定すると入力必須になる（案内に書いた人だけ通れる） |
| `FIRST_SETUP_REQUIRE_UID` | `on` にすると、LINE経由（`?uid=`付き）で来た人だけ設定できる |

いずれも**再デプロイ不要**（実行時に読みます）。何も設定しなければ「メアドを知っていれば誰でも設定できる」状態なので、
公開したら `FIRST_SETUP_UNTIL` だけは入れておくのが安全です。

## LINE連携

### いま入っているもの
LINEのボタン→自作ページ転送で `?uid=[[uid]]` を付けてアプリを開くと、
**ログイン時にそのUIDを「閲覧者一覧」H列へ自動保存**します（`?lineuid=` でも可）。
一度アプリを開けば端末に記憶するので、次からURLにuidが無くても紐付いたままです。

### LINEだけでログインできるようにする（将来）
**2か所ともONにしたときだけ**有効になります（事故防止のため二重ロック）。
1. `js/config.js` の `LINE_QUICK_LOGIN: true`
2. GASのスクリプトプロパティ `LINE_QUICK_LOGIN` に `on`（**再デプロイ不要**）

ONにすると、`?uid=…` 付きで開いた人はパスワードなしで入れます（UIDが閲覧者一覧に登録済みの場合のみ）。

## こまったとき

| 症状 | 原因・対処 |
|---|---|
| ログインできない | 閲覧者一覧のメール／パスワードの前後に空白がないか。状態が`停止`でないか |
| 「10分ほどおいてから」と出る | 連続10回間違えた時のロック。10分待てば解除 |
| 動画が真っ黒／再生できない | Vimeoの埋め込みドメイン制限に公開ドメインが入っているか |
| 追加したのに出てこない | コース設定のタグと閲覧者のタグが一致しているか（全角/半角も一致が必要） |
| 動画に🔒が付いている | H列の視聴開始がまだ来ていない／I列の視聴期限が過ぎている |
| お知らせが見えない人がいる | 宛先タグを確認（空欄＝全員。タグ指定はそのタグを持つ人だけ） |
| 「セットアップ未完了」と出る | `js/config.js` の `GAS_URL` が空 |
| 目次ボタンが出ない | 補足欄が `0:12:30　見出し`（時刻＋スペース＋見出し）の形になっているか |

### 画面だけ見たいとき（デモモード）
URLの末尾に `?mock=1` を付けると、GASに繋がずダミーデータで動きます。
- 受講生：`index.html?mock=1`（`demo@example.com` / `demo`）
- 運営：`admin.html?mock=1`（`admin@example.com` / `demo`／保存はできません）

視聴期限・公開前・お知らせ・アンケートの見え方もダミーで確認できます。

## GASを更新するときの作法（事故防止）

エルラボ＋と同じルールです。
- **「末尾に追記」ではなく必ず「全文差し替え版」で貼る**（Apps ScriptはCtrl+Aが全選択のため）
- 貼ったら「デプロイを管理」→鉛筆→**新しいバージョン**→デプロイ（**URLは変わりません**）
- 反映後に `…/exec?action=ping` で `pong` を確認
- このリポジトリの `gas/Code.gs` を**本番の鏡**として最新に保つ
